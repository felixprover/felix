\section{Typed logical conditionals}

Logical conditionals are defined from selection.  Their conditions are
propositions in the logical framework, not set-coded truth values.  Typed
logical selection has a witness law only for an inhabited predicate.  Each
conditional below explicitly supplies such a witness in either truth case;
no value is specified for an unsatisfied selection predicate in general.

\begin{definition}\label{logical_if_set}
    $\logicalIfSetOp : \Prop\to\Set\to\Set\to\Set
        =\fun{p:\Prop}{
            \fun{a,b:\Set}{
                    \Select[\Set]{
                        \fun{x:\Set}{(p\land x=a)\lor(\lnot p\land x=b)}}}}$.
\end{definition}

\begin{proposition}\label{logical_if_set_true}
    $\forall p:\Prop.\ \forall a,b:\Set.
        p\implies
        \Apply{\logicalIfSetOp}{p,a,b}=a$.
\end{proposition}
\begin{proof}
    Fix $p,a,b$.
    Assume $p$.
    $\exists x:\Set.\ (p\land x=a)\lor(\lnot p\land x=b)$.
    Follows by \auto{logical_if_set}.
\end{proof}

\begin{proposition}\label{logical_if_set_false}
    $\forall p:\Prop.\ \forall a,b:\Set.
        \lnot p\implies
        \Apply{\logicalIfSetOp}{p,a,b}=b$.
\end{proposition}
\begin{proof}
    Fix $p,a,b$.
    Assume $\lnot p$.
    $\exists x:\Set.\ (p\land x=a)\lor(\lnot p\land x=b)$.
    Follows by \auto{logical_if_set}.
\end{proof}
